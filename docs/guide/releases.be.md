# Версія і абмежаванні

## 0.3.0 · 25 кастрычніка 2026

Выпраўлены спецыяльныя радковыя першасныя ключы ў буферы і тэрмін дзеяння папярэдняга прагляду. Дададзены кэшаваныя агрэгаты з праверкай правоў, абарона ад састарэлых адказаў і аўтаматычнае выяўленне `ModelSheetAdmin`. Публікацыя патрабуе поўнай матрыцы CI, тэстаў браўзера і пакета, а таксама строгай праверкі дакументацыі.

Усталюйце стабільны выпуск з PyPI:

[GitHub Release](https://github.com/svalench/django-modelsheet/releases/tag/v0.3.0) · [PyPI](https://pypi.org/project/django-modelsheet/0.3.0/)

```bash
python -m pip install --upgrade django-modelsheet==0.3.0
```

Зрабіце рэзервовую копію БД і прыпыніце запіс ды фонавых выканаўцаў. Усталюйце пакет, выканайце `python manage.py migrate` і `python manage.py collectstatic --noinput`, перазапусціце праграму і выканаўцаў, перазагрузіце ўкладкі. Міграцыя `0002_operation_preview_expires_at` захоўвае аўдыт, здымкі і элементы аперацый. Старыя непацверджаныя планы губляюць сілу: стварыце новы прагляд перад пацвярджэннем. Пацверджаныя аперацыі можна працягнуць.

Тэрмін прагляду фіксуецца пры завяршэнні падрыхтоўкі. Адмена, працяг і змена `preview_ttl_seconds` не падаўжаюць яго. Пратэрмінаваны непацверджаны план вяртае `expired_preview` (409); стварыце новы прагляд. Працяг пустога плана захоўвае пусты набор запісаў. Пацверджаныя аперацыі можна працягнуць пасля заканчэння тэрміну.

## 0.3.0a1 · 24 кастрычніка 2026

Першая адкрытая альфа аб'ядноўвае рэдагаванне дыяпазонаў, лакальны буфер, бяспечнае захаванне, формулы і масавыя аперацыі з папярэднім праглядам.

[Усталяваць з PyPI](https://pypi.org/project/django-modelsheet/0.3.0a1/){ .md-button .md-button--primary }
[GitHub Release](https://github.com/svalench/django-modelsheet/releases/tag/v0.3.0a1){ .md-button }

```bash
python -m pip install django-modelsheet==0.3.0a1
```

Уваходзяць яўная рэгістрацыя мадэляў, буфер абмену, запаўненне, адмена, Decimal-разлікі, серверныя запыты, выяўленне канфліктаў, нязменныя планы, аўдыт, ідэмпатэнтнасць і кантракт фонавага адаптара. Таксама гатовая статыка, дэма і MIT-ліцэнзія.

## Межы 0.3.0

| Магчымасць | Цяперашнія паводзіны |
| --- | --- |
| Стварэнне / выдаленне | Стандартны Admin |
| FK | Дазволены паказ і фільтры, без рэдактара |
| M2M | Без рэдактара |
| Формулы | Аднаразовыя значэнні або віртуальныя калонкі |
| Адмена | Лакальны буфер да захавання |
| Імпарт / экспарт файлаў | Адкладзеныя; TSV-буфер даступны |
| Фонавая чарга | Адаптар праекта |
| Некалькі БД | Толькі `default` |
| Парадак вылічальных калонак | Не падтрымліваецца |

Серверная адмена, рэдактары сувязей, імпарт/экспарт, fast-save, пастаянныя формулы і курсорная пагінацыя — кірункі развіцця без абяцаных тэрмінаў.
