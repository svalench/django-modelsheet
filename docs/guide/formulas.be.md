# Прыклады формул

Формула пачынаецца з `=`. Кліент паказвае вынік, сервер перад запісам пералічвае і правярае яго.

!!! info "Аднаразовае прысваенне"
    Поле мадэлі захоўвае вынік, а не пастаянную залежнасць. Для вылічальнай калонкі толькі для паказу выкарыстоўвайце `sheet_computed_fields`.

## Гатовыя формулы

| Мэта | Формула |
| --- | --- |
| Павысіць цану на 7% | `=ROUND([price]*1.07,2)` |
| Зніжка 10% | `=ROUND([price]*0.9,2)` |
| Кошт запасаў | `=[price]*[stock]` |
| Статус паводле запасу | `=IF([stock]>0,"ready","order")` |
| Замяніць NULL | `=IFNULL([note],"Без заўвагі")` |
| Назва вялікімі літарамі | `=UPPER([name])` |
| Год з даты | `=YEAR([available_on])` |
| Сума загружаных цэн | `=SUM(price)` |
| Апрацаваць памылку дзялення | `=IFERROR([price]/[stock],0)` |

Палі мусяць існаваць і быць бачнымі карыстальніку. Значэнні статусу павінны адпавядаць choices.

## Зыходныя значэнні

`[price]` чытае зыходную цану, таму `=[price]*1.07` у самой цане не стварае цыкл. `1200.00` становіцца `1284.00`. Усе прысваенні масавай аперацыі таксама чытаюць зыходныя даныя незалежна ад парадку.

## Спасылкі на ячэйкі { #cell-references }

| Спасылка | Значэнне |
| --- | --- |
| `B7` | Сёмы загружаны радок, другая бачная калонка даных |
| `$B$7` | Фіксаваныя радок і калонка пры капіраванні |
| `B$7` / `$B7` | Фіксаваны радок / фіксаваная калонка |
| `B1:B20` | Дыяпазон цяперашняга здымка |

Пазіцыйныя спасылкі бачаць незахаваныя змены. Выхад за межы дае `#REF!`, цыкл — `#CYCLE!`. На наступных старонках `B7` усё адно азначае сёмы радок той старонкі.

## Вылічальныя калонкі

```python
sheet_computed_fields = {
    "inventory_value": "=[price]*[stock]",
    "availability": '=IF([stock]>0,"У наяўнасці","Пад заказ")',
}
```

Калонкі толькі для чытання; серверны парадак і фільтраванне па іх у гэтай версіі не падтрымліваюцца.

## Агрэгаты і дакладнасць

`SUM`, `AVG`, `COUNT` ахопліваюць загружаны дыяпазон, а не ўсе запісы БД. `COUNT` лічыць лікавыя значэнні. NULL, пустыя значэнні і нелікавы тэкст прапускаюцца.

Масавыя формулы дазваляюць толькі імянныя спасылкі. `QSUM`, `QAVG`, `QCOUNT` працуюць па нязменным наборы папярэдняга прагляду, напрыклад `=[price]/QSUM([price])`.

Decimal выкарыстоўвае 28 значных лічбаў і `ROUND_HALF_EVEN`; поле мадэлі акругляе паводле `decimal_places`. `ROUND(8.5,0)` дае `8`, `ROUND(9.5,0)` — `10`.

| Памылка | Прычына |
| --- | --- |
| `#REF!` | Недаступная спасылка або выхад за здымак |
| `#CYCLE!` | Цыкл залежнасцей |
| `#DIV/0!` | Дзяленне на нуль |
| `#VALUE!` | Несумяшчальныя тыпы |
| `#NAME?` | Невядомая функцыя або імя |
| `#N/A` | Няма ўваходнага значэння |
| `#NUM!` | Недапушчальны лікавы вынік |
| `#LIMIT!` | Перавышаны бюджэт вылічэння |

Поўныя правілы: [спецыфікацыя формул](../formulas.md).
