# Масавыя аперацыі

Прыклад: знайсці гатовыя тавары з запасам менш за 10, павысіць цану на 7% і задаць статус `order`.

## 1. Выберыце вобласць

У **Bulk change** выберыце вылучаныя радкі старонкі або ўсе адпаведныя запісы, у тым ліку на іншых старонках. Вобласць заўсёды абмяжоўваецца queryset, актуальнымі правамі і палітыкай праекта.

```json title="Эквівалентная ўмова API"
{"and":[{"field":"stock","op":"lt","value":10},{"field":"status","op":"eq","value":"ready"}]}
```

## 2. Дадайце прысваенні

| Поле | Новае значэнне |
| --- | --- |
| `price` | `=ROUND([price]*1.07,2)` |
| `status` | `order` |

Кожнае прысваенне чытае зыходныя даныя; парадак не ўплывае на вынік.

## 3. Пабудуйце папярэдні прагляд

Ён фіксуе ўсе PK кандыдатаў, зыходныя версіі, вылічаныя змены і памылкі. Інтэрфейс паказвае колькасць і першыя 50 вынікаў. Новыя супадзенні пазней не дадаюцца. Змена ўмоў або формул патрабуе новага прагляду.

## 4. Пацвердзіце

Выкананне прымае ID гатовай аперацыі. Паўтор не прымяняе нацэнку двойчы. Перад запісам паўторна правяраюцца доступ і версіі. Змененыя запісы даюць канфлікт; іх выпраўленне патрабуе новага плана.

## 5. Праверце справаздачу

Гісторыя захоўвае статус, лічыльнікі, вынікі радкоў і памылкі. Актуальныя правы абмяжоўваюць і гісторыю, і бачныя палі.

| Рэжым | Гарантыя |
| --- | --- |
| Сінхронны | Адна транзакцыя: усё або нічога |
| Фонавы | Запіс порцыямі; магчыма частковае выкананне |

## Вялікія аперацыі

Парог фону па змаўчанні — 5000 радкоў, порцыя — 200. Без `BackgroundAdapter` перавышэнне адхіляецца да цяжкай апрацоўкі. Вялікі прагляд таксама будуецца адаптарам. Чарга і Celery worker не ўваходзяць у пакет.

Адмена спыняе наступныя порцыі без адкату ўжо выкананага. Працяг апрацоўвае незавершаныя элементы без паўтору паспяховых. Гл. [фонавы кантракт](../background.md) і [HTTP API](../api.md).
