# Дэмапраект

Рэпазіторый утрымлівае тавары, катэгорыі і заказы. Каманда напаўнення стварае 500 тавараў для праверкі старонак, фільтраў і масавых змен.

## Лакальны запуск

```bash
 git clone https://github.com/svalench/django-modelsheet.git
 cd django-modelsheet
 python -m venv .venv
 source .venv/bin/activate
 python -m pip install -e '.[test]'
 python manage.py migrate
 python manage.py seed_demo --create-user
 python manage.py runserver
```

У Windows актывуйце асяроддзе праз `.venv\Scripts\activate`. Адкрыйце `http://127.0.0.1:8000/admin/shop/product/sheet/`.

!!! warning "Уліковы запіс толькі для лакальнай працы"
    `--create-user` стварае карыстальніка `admin` з паролем `admin`. Дэманалады і гэты запіс прызначаныя толькі для лакальнай распрацоўкі.

Гатовая статыка ўжо ўваходзіць у рэпазіторый. Калі змяняеце frontend:

```bash
cd frontend
npm ci
npm run build
```

## Паспрабуйце тры сцэнары

### Праверка мадэлі

Задайце цану ніжэйшую за `cost_price` і націсніце **Save**. Праверка верне памылку, а буфер захаваецца. Выпраўце цану і паўтарыце захаванне.

### Формула дыяпазону

У першую ячэйку цаны ўвядзіце `=ROUND([price]*1.07,2)`, вылучыце вертыкальны дыяпазон і запоўніце ўніз праз Ctrl/Cmd+D. Праверце вынікі і захавайце.

### Канфлікт са стандартным Admin

Загрузіце радок у табліцы, затым змяніце той жа тавар у форме Admin у іншай укладцы. Захаванне буфера выявіць канфлікт замест ціхага перазапісу. Загрузіце актуальныя даныя і паўторна ўжывіце змены. Падрабязней пра [канкурэнтны доступ](permissions.md#concurrency).
