# 编辑表格

表格编辑已有记录。记录由主键标识；行号只表示当前加载页面中的位置。

## 本地更改与保存

双击单元格或使用公式栏编辑。更改保留在本地缓冲区，点击 **Save** 后作为一个原子请求提交：全部成功，或全部回滚。验证失败不会清空缓冲区，可修正后重试。撤销和重做仅作用于保存前的更改。

| 操作 | 快捷键 |
| --- | --- |
| 导航 | 方向键、Tab |
| 编辑所选单元格 | F2、直接输入、Enter 或双击 |
| 扩展选区 | Shift + 导航键 |
| 保存 | Ctrl/Cmd+S |
| 撤销 / 重做 | Ctrl/Cmd+Z / Ctrl/Cmd+Y |
| 向下 / 向右填充 | Ctrl/Cmd+D / Ctrl/Cmd+R |
| 复制 / 粘贴 | Ctrl/Cmd+C / Ctrl/Cmd+V |

## 剪贴板与填充

从 Excel 复制区域后粘贴到活动单元格。TSV 以制表符分列、换行符分行：

```text title="price 与 stock 的示例值"
1200.00	10
850.50	25
3400.00	8
```

只读单元格会被跳过并提示，其余更改一起保存。

小数接受小数点或逗号。日期和时间使用字段编辑器，并按当前语言显示；存储值仍是 ISO 8601（`2026-10-24`）。空值对于 nullable 字段转为 NULL，对于文本转为空字符串，其他类型可能验证失败。要输入以 `=` 开头的普通文本，请加单引号：`'=SUM(A1:A2)`。布尔值使用复选框，选项使用列表，外键使用自动完成，且只提供相关 ModelAdmin 允许查看的记录。多对多标签只读。

先在顶部单元格输入值或公式，再选中纵向区域并按 Ctrl/Cmd+D。相对引用随位置移动，绝对引用保持不变。参见[单元格引用](formulas.md#cell-references)。

## 搜索、筛选与排序

搜索在服务器端对允许的 `search_fields` 执行。按 Enter 或点击 **Search**。筛选使用本地化运算符和对应类型的输入；当前筛选显示为标签，而不是原始 JSON。多字段排序自动加入主键作为稳定的次级顺序。

使用 **Sort**，或 Alt+点击列标题；Alt+Shift+点击可追加排序字段。普通点击选择列。支持调整列宽、隐藏和冻结列；视图状态保存在 URL 中。

更换页面、筛选或顺序前需保存或放弃更改。位置公式绑定当前快照，跨快照复制受到限制。

## 标准 Admin

**Ordinary Admin** 仅在能精确表达条件、顺序和页码时才转换视图，否则说明原因并阻止切换。

拥有模型 add 或 delete 权限时，**Add row** 和 **Delete rows** 与其他更改同一次原子保存。**Revert save** 在指纹仍匹配时让服务器撤销上次保存。**Find** 通过本地缓冲替换当前页文本。**Views** 把筛选、排序、列、冻结和列宽保存在浏览器中，也可以在服务器上保存共享视图。**Export** 下载整个筛选结果。**Import** 把 CSV 或 XLSX 送入批量预览。参见[集成边界](../extensions.md)。
