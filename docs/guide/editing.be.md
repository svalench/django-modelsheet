# Праца з табліцай

Табліца рэдагуе існыя запісы. Запіс вызначаецца першасным ключом; нумары радкоў датычацца загружанай старонкі.

## Лакальныя змены і захаванне

Двойчы націсніце ячэйку або скарыстайцеся радком формул. Змены застаюцца ў лакальным буферы, пакуль **Save** не адправіць адзін атамарны запыт: захоўваюцца ўсе радкі або ўвесь запыт адкочваецца. Пасля памылкі праверкі буфер застаецца для выпраўлення і паўтору. Адмена і паўтор дзейнічаюць да захавання.

| Дзеянне | Клавішы |
| --- | --- |
| Навігацыя | Стрэлкі, Tab, Enter |
| Пашырыць вылучэнне | Shift + навігацыя |
| Захаваць | Ctrl/Cmd+S |
| Адмяніць / паўтарыць | Ctrl/Cmd+Z / Ctrl/Cmd+Y |
| Запоўніць уніз | Ctrl/Cmd+D |
| Скапіраваць / уставіць | Ctrl/Cmd+C / Ctrl/Cmd+V |

## Буфер абмену і запаўненне

Скапіруйце дыяпазон з Excel і ўстаўце ў актыўную ячэйку. TSV выкарыстоўвае табуляцыю паміж калонкамі і перавод радка паміж запісамі:

```text title="Значэнні для price і stock"
1200.00	10
850.50	25
3400.00	8
```

Ячэйкі толькі для чытання прапускаюцца з паведамленнем. Астатнія змены захоўваюцца разам.

Дзесятковы падзельнік — кропка, даты — ISO 8601, напрыклад `2026-10-24`. Пустое значэнне становіцца NULL для nullable-поля, пустым радком для тэксту або памылкай для іншых тыпаў. Перад звычайным тэкстам з `=` пастаўце апостраф: `'=SUM(A1:A2)`.

Для запаўнення ўніз увядзіце верхняе значэнне або формулу, вылучыце вертыкальны дыяпазон і націсніце Ctrl/Cmd+D. Адносныя спасылкі зрушваюцца, абсалютныя застаюцца. Гл. [спасылкі на ячэйкі](formulas.md#cell-references).

## Пошук, фільтры і парадак

Пошук выконваецца на серверы па дазволеных `search_fields`. Фільтры падтрымліваюць групы AND/OR. Да парадку па некалькіх палях дадаецца PK для стабільнасці.

Выкарыстоўвайце **Sort** або Alt+націск загалоўка; Alt+Shift+націск дадае поле. Звычайны націск вылучае калонку. Шырыню, бачнасць і замацаванне калонак можна змяняць; стан захоўваецца ў URL.

Перад зменай старонкі, фільтра або парадку захавайце ці адкіньце буфер. Пазіцыйныя формулы звязаныя са здымкам; капіраванне паміж здымкамі абмежаванае.

## Стандартны Admin

**Ordinary Admin** пераносіць умовы, парадак і старонку толькі пры дакладным прадстаўленні. Інакш пераход блакуецца з тлумачэннем. Стварэнне і выдаленне застаюцца ў стандартным Admin. Гл. [межы інтэграцыі](../extensions.md).
