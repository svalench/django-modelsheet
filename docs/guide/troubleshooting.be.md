# Вырашэнне праблем

## Няма кнопкі Spreadsheet

Праверце, што `modelsheet` усталяваны і міграцыі выкананыя, `app.Model` дазволеная, зарэгістраваны Admin наследуе `ModelSheetAdmin`, настроеныя `sheet_fields` і правы карыстальніка. Выканайце `python manage.py check`.

## Поле толькі для чытання

Яно мусіць уваходзіць у `sheet_editable`. Таксама дзейнічаюць `readonly_fields`, правы мадэлі і поля, аб'ектныя метады Admin і палітыка праекта. FK/M2M і вылічальныя калонкі ў альфе не рэдагуюцца.

## Канфлікт захавання

Зыходны запіс або залежнасць змяніліся ці здымак пратэрмінаваны. Захавайце патрэбныя праўкі асобна, загрузіце актуальныя даныя і ўжывіце іх нанова. Не падмяняйце `version`. Калі страчаны толькі адказ, паўтарыце дакладна той жа запыт з зыходным ключом ідэмпатэнтнасці.

## Рэжым транзакцый SQLite

```python
DATABASES["default"].setdefault("OPTIONS", {})["transaction_mode"] = "IMMEDIATE"
```

Аднаго `select_for_update()` недастаткова. Занятая БД вяртае памылку, якую можна паўтарыць; выкарыстоўвайце зыходныя запыт і ключ.

## Памылкі формул

`#REF!`: праверце парадак калонак і межы здымка; нумары радкоў лакальныя для старонкі. `#LIMIT!`: спрасціце выраз або дыяпазон. Павелічэнне лімітаў `MODELSHEET["formula"]` павінна ўлічваць нагрузку праекта.

## Вялікая аперацыя адхіленая

Пасля `bulk_background_threshold` наладзьце [BackgroundAdapter](../background.md). Павелічэнне парога не стварае worker або чаргу. Таксама праверце `max_bulk_rows` і правы масавых аперацый.

## Немагчыма вярнуцца ў стандартны Admin

Фільтр або парадак нельга дакладна прадставіць. Спрасціце іх. Уласныя list filters, пошук па сувязях і парадак праз выразы могуць патрабаваць асобнай інтэграцыі.

## JavaScript не загружаецца ў production

Выканайце `collectstatic`, праверце абслугоўванне `STATIC_ROOT` і адсутныя рэсурсы `modelsheet` у сеткавых запытах браўзера. Гатовыя файлы ўваходзяць у wheel; npm у праекце-спажыўцы не патрэбны.

## Паведаміць пра памылку

Стварыце [GitHub issue](https://github.com/svalench/django-modelsheet/issues) з версіямі пакета/Python/Django, БД, мінімальнымі наладамі Admin і крокамі паўтарэння. Прыбярыце сакрэты і асабістыя даныя.
