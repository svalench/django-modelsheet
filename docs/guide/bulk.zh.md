# 批量操作

示例：筛选库存低于 10 且状态为 ready 的商品，涨价 7%，并将状态改为 `order`。

## 1. 选择范围

在 **Bulk change** 中选择当前页高亮行，或选择所有匹配记录（包括其他页）。范围始终受 queryset、当前权限和项目策略限制。

```json title="等价的 API 条件"
{"and":[{"field":"stock","op":"lt","value":10},{"field":"status","op":"eq","value":"ready"}]}
```

## 2. 添加赋值

| 字段 | 新值 |
| --- | --- |
| `price` | `=ROUND([price]*1.07,2)` |
| `status` | `order` |

所有赋值读取原始数据，顺序不影响结果。

## 3. 生成预览

预览固定所有候选主键、原始版本、计算结果和错误。界面展示总数与前 50 条结果。后来才匹配条件的商品不会加入计划；更改条件或公式需要重新预览。

如果对象权限隐藏了任何候选行，整个预览会在读取源值或计算聚合之前被拒绝。
请将 queryset 或筛选范围缩小到可读集合；系统不会静默移除隐藏行来改变聚合范围。
添加或删除赋值、筛选组也会使预览失效。

使用相同幂等键重试相同请求会返回已有计划，即使视图快照已过期或被删除。
系统仍检查当前访问权限，且不会延长计划的确认期限。

公式解析及 `QSUM`/`QAVG`/`QCOUNT` 结果只在一个不可变计划内缓存。
惰性分支和公式步数/时间限制仍然有效；命中缓存时仍计算源值的逻辑数量。
不同预览不会共享缓存数据。

## 4. 确认执行

执行接受已生成的操作 ID。重复调用不会再次涨价。写入前会重新检查权限和版本。已变化的记录产生冲突，修正后需建立新计划。

## 5. 查看报告

历史记录包含状态、计数、逐行结果和错误；可见字段和历史访问均按当前权限判断。

| 模式 | 保证 |
| --- | --- |
| 同步 | 单个事务，全成或全败 |
| 后台 | 分批提交，可能部分完成 |

## 大型操作

默认后台阈值为 5000 行，批次大小为 200。未配置 `BackgroundAdapter` 时，超出阈值会在昂贵处理前拒绝。大型预览也通过适配器运行。软件包不附带队列或 Celery worker。

取消只停止后续批次，不回滚已完成更改。恢复只处理未完成项，不重复成功项。参见[后台契约](../background.md)与 [HTTP API](../api.md)。

预览截止时间在准备完成时固定。取消、恢复以及修改 `preview_ttl_seconds` 均不会延长截止时间。过期且未确认的计划返回 `expired_preview`（409），需要重新预览。恢复空预览会保留原始空记录集。已确认的任务在截止时间后仍可恢复执行。

备份数据库并暂停应用写入和后台任务。安装新包，运行 `python manage.py migrate` 和 `python manage.py collectstatic --noinput`，然后重启应用及后台任务并刷新浏览器页面。迁移 `0002_operation_preview_expires_at` 保留审计历史、快照和操作明细。旧的未确认预览将保守地标记为过期，确认前必须重新预览。已确认的任务仍可恢复执行。
