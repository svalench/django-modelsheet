# Спецификация формул

Формулы начинаются с `=` и разбираются ограниченной грамматикой на сервере и клиенте. Выполнение Python, произвольного SQL, доступ к файловой системе и сети отсутствуют. Перед записью сервер пересчитывает результат и валидирует значение модели.

Практические рецепты: [формулы на примерах](guide/formulas.md).

## Операторы и литералы

Арифметика: `+ - * / ^`; конкатенация: `&`; сравнения: `= <> != < <= > >=`. Поддерживаются скобки и унарные знаки.

Аргументы разделяются запятыми. Строки заключаются в двойные кавычки; для кавычки внутри строки удвойте её. Литералы: `TRUE`, `FALSE`, `NULL`.

Decimal-расчёты используют 28 значащих цифр и `ROUND_HALF_EVEN`; `DecimalField` округляет до своих десятичных знаков. Степень должна быть целым числом от −100 до 100.

## Функции

| Группа | Функции |
| --- | --- |
| Условия | `IF`, `IFERROR` |
| Числа | `ROUND`, `ABS`, `MIN`, `MAX` |
| Агрегаты загруженного диапазона | `SUM`, `AVG`, `COUNT` |
| Текст | `UPPER`, `LOWER`, `CONCAT` |
| Даты | `TODAY`, `YEAR`, `MONTH`, `DAY` |
| Пустые значения | `ISNULL`, `IFNULL`, `COALESCE` |
| Агрегаты массовой операции | `QSUM`, `QAVG`, `QCOUNT` |

`IF` и null-coalescing функции вычисляют только необходимую ветку. `IFERROR` не подавляет ошибки бюджета вычисления.

## Ссылки

`[price]` читает исходную цену строки. Присваивание цене `=[price]*1.07` не создаёт цикл.

`B7` — седьмая загруженная строка и вторая отображаемая колонка данных. Номера локальны для страницы, в том числе на следующих страницах. `$B$7` фиксирует координаты при копировании, но не обращается к другой странице. Частично абсолютные ссылки также поддерживаются.

Позиционные ссылки учитывают локальный буфер. Выход за пределы снимка и циклы отклоняются.

## Агрегаты и NULL

`SUM(B1:B20)` и `SUM(price)` работают по загруженному представлению. `SUM`, `AVG`, `COUNT` пропускают NULL, пустые значения и нечисловой текст; `COUNT` считает числовые значения.

Пустой `SUM`/`COUNT` равен нулю, пустой `AVG`/`MIN`/`MAX` даёт `#N/A`. Арифметика с NULL даёт `#N/A`. Пустая строка, ноль и NULL — разные значения.

Даты передаются в ISO-формате. `TODAY` фиксируется на UTC-дате снимка или предпросмотра, поэтому полночь не меняет подтверждённый план.

## Массовые формулы

Разрешены только именованные ссылки. `QSUM([price])`, `QAVG([price])`, `QCOUNT([price])` читают неизменяемые исходные данные кандидатов, зафиксированные предпросмотром. Фильтр при выполнении не запускается повторно для добавления новых совпадений.

Все присваивания читают исходную строку и сохранённые значения предпросмотра; порядок присваиваний не влияет на результат.

## Ошибки и бюджеты

Коды: `#REF!`, `#CYCLE!`, `#N/A`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#NUM!`, `#LIMIT!`.

Ограничены длина выражения, глубина AST, шаги и время, размер степени. Цепочки межъячеечных зависимостей ограничены 100 активными ячейками. Основные лимиты задаются в [MODELSHEET.formula](guide/configuration.md).

## Жизненный цикл

Смена представления требует сохранения или отмены буфера. Сохранение связано с ID снимка и полным состоянием вида. Просроченные снимки отклоняются.

Внутреннее копирование отслеживает снимок и блокирует позиционную вставку после смены вида. Формулы внешнего clipboard интерпретируются в текущем представлении.

Формула — однократное присваивание или виртуальная колонка. Постоянные зависимости в модели не хранятся. Виртуальные колонки только для чтения, без серверной сортировки и фильтрации в этой версии.
